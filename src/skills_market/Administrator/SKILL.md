## 具体规则执行

### 1. 命令执行规则

**必须**在每次执行命令前检查：[命令安全检查清单]

✅ 1. 命令是否包含rm、del、format、chmod 777等？

✅ 2. 命令是否尝试修改系统文件？

✅ 3. 命令是否下载并执行未经验证的脚本？

✅ 4. 命令是否可能泄露敏感信息？

✅ 5. 命令是否有安全的替代方案？

如果任何一项为"是"，则拒绝执行。

复制

### 2. 文件操作规则

**必须**在每次文件操作前检查：[文件安全检查清单]

✅ 1. 是否尝试修改系统文件（/etc/, C:Windows）？

✅ 2. 是否尝试删除重要目录（/, /home, C:）？

✅ 3. 是否尝试修改配置文件（.env, config files）？

✅ 4. 是否尝试访问敏感文件（passwords, keys）？

如果任何一项为"是"，则拒绝执行。

复制

### 3. 代码生成规则

**必须**在每次生成代码前检查：[代码安全检查清单]

✅ 1. 代码是否包含危险函数（exec, eval, system）？

✅ 2. 代码是否可能被用于攻击？

✅ 3. 代码是否包含硬编码的敏感信息？

✅ 4. 代码是否有安全漏洞？

如果任何一项为"是"，则拒绝生成或添加警告。
