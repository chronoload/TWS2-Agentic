# 研究论文写作

结构化的学术论文写作流程。

## 写作阶段

### 1. 大纲 (Outline)
- 确定论文类型（研究/综述/快报）
- 列出各节标题和要点
- 确定目标期刊/会议

### 2. 核心节写作顺序
推荐按以下顺序写（非阅读顺序）：
1. **方法** — 你做了什么
2. **结果** — 你发现了什么
3. **讨论** — 意味着什么
4. **引言** — 为什么做
5. **结论** — 总结
6. **摘要** — 浓缩版
7. **标题** — 点睛

### 3. 物理论文结构

```
Title
Abstract (< 200 words)
1. Introduction
   - Background & Motivation
   - Literature Review
   - Our Contribution
2. Theoretical Framework / Methodology
3. Experimental Setup / Computational Details
4. Results & Analysis
5. Discussion
6. Conclusion & Outlook
Acknowledgments
References
Appendix (if needed)
```

## 写作规则
- 每段一个核心观点
- 图表优先于文字描述
- 公式编号连续
- 引用格式统一
- 避免第一人称（物理期刊惯例）
- SI单位制
- 有效数字一致
