## 使用方式

### 方式1：Python API（推荐）

```python
import sys
sys.path.insert(0, '.codebuddy/skills/ima-knowledge-base/scripts')
from pdf_to_ima_final import PDFToIMAWorkflow

workflow = PDFToIMAWorkflow(
    pdf_path=r"C:\path\to\file.pdf",
    ima_exe_path=r"F:\ima.copilot\ima.copilot.exe"
)

# 准备知识库条目
workflow.prepare_kb_entry(
    tags=["PDF", "文档", "数学"],
    description="文档描述"
)

# 生成上传指南
workflow.generate_upload_guide()

# 启动IMA客户端
workflow.launch_ima()
```

## 已知问题和限制

### 1. Argparse中文路径问题
**问题：** argparse在处理包含中文和空格的路径时出错

**解决方案：**
- 使用Python API调用
- 使用测试脚本
- 修改脚本内部参数

### 2. 编码问题
**问题：** Windows控制台GBK编码不支持emoji

**解决方案：**
- 移除emoji，使用ASCII字符
- 确保文件使用UTF-8编码
- 避免特殊字符

### 3. 依赖问题
**问题：** toc_tools目录的导入可能失败

**解决方案：**
- 使用try-except处理导入失败
- 提供降级方案
- 跳过非核心功能
